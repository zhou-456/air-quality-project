# STM32F103 多参数环境监测系统
> 🎓 本科毕业设计 | FreeRTOS多任务环境监测设备 | 本地LCD显示 + OneNET云平台远程监测

## 项目概述
本系统以STM32F103C8T6为主控芯片，基于FreeRTOS实时操作系统实现多任务并发运行。系统采集温度、湿度、PM2.5、eCO₂、TVOC、硫化氢(H₂S)、氨气(NH₃)多项环境指标。
设备支持本地彩色LCD可视化交互，可自定义报警阈值，阈值保存在DS1302的片内RAM实现掉电保存；环境数值超标时触发蜂鸣器与LED声光报警。ESP8266‑01S WiFi模块通过MQTT协议定时上传JSON格式传感器数据到中国移动OneNET物联网云平台，电脑、手机可在线远程查看环境状态。

项目全部驱动自主编写，使用互斥锁解决多任务共享数据访问冲突，任务之间解耦，便于功能二次修改与拓展。

## 🧩软件任务划分
本项目采用FreeRTOS CMSIS‑RTOS V1，划分5个业务任务，各任务职责独立：
1. **Sensor_Task 传感器采集任务**
周期读取所有传感器，对原始数据做滑动平均、中值滤波处理，调用发布接口更新全局传感器数据。上电存在15s传感器预热时间，规避传感器初始读数误差。

2. **LCD_Task 显示任务**
读取受互斥锁保护的传感器数据；实现4套UI页面渲染；系统上电自动从DS1302 RAM读取保存的报警阈值。页面数值根据阈值自动变换颜色：绿色正常，黄色警告，红色危险。

3. **System_Task 系统业务任务**
实现按键状态机扫描，支持短按、长按识别；处理阈值的增加、减少、切换、保存逻辑；判断环境数据是否超过危险阈值，控制蜂鸣器、报警LED输出。

4. **WiFi_Task 网络任务**
ESP8266模块初始化、WiFi重连、MQTT断线重连逻辑；建立MQTT连接后，每10秒上报一次完整传感器JSON数据包；增加重传机制，提升网络不稳定场景下上报成功率。

5. **Heartbeat_Task 心跳任务（预留）**
可拓展用于系统运行状态监控、看门狗喂狗等功能。

> ✅ 数据安全：全部传感器全局数据通过互斥锁(mutex)读写，避免多任务同时读写造成的数据错乱。

## 📺UI页面说明
1. **MAIN 主监控页**
展示温度、湿度、CO₂、TVOC、PM2.5，年月日时间；底部提示按键操作。

2. **GAS 气体详情页**
重点展示H₂S硫化氢、NH₃氨气，同时显示CO₂、TVOC、PM2.5气体参数。

3. **SYS 系统状态页**
显示WiFi、MQTT、各个传感器工作状态；统计系统上电运行时长。

4. **SET 阈值设置页**
修改PM2.5、H₂S、NH₃的警告阈值、危险阈值。
- KEY1：数值+1
- KEY2：数值‑1
- KEY3：切换下一项参数
- KEY4：保存阈值到DS1302 RAM，掉电不丢失

## 🎮按键操作说明
- KEY1：切换显示页面
- KEY2：翻转板载LED状态
- KEY3短按：蜂鸣器提示音；KEY3**长按800ms**：进入阈值设置页面
- KEY4：设置页面下保存参数；普通页面无动作

⚠️重要注意事项
MQ 系列气体传感器需要预热，上电初期读数不准，等待预热完成再观察数据。
DS1302 必须接上 CR2032 纽扣电池，断电后时间、保存的报警阈值才可以保留。
ESP8266‑01S 为 3.3V 电平，严禁接入 5V 电压，串口使用 USART2。
OneNET 物模型的属性标识符必须和上报 JSON 字段一一对应，否则云平台无法解析数据。
本项目为毕业设计参考代码，可以自由学习修改，实际产品需要增加更多容错、异常处理逻辑。
